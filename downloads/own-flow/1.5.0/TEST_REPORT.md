## 实际浏览器检查

- 首页新入口可到任务状态机、多智能体工作台与交互辨识；战术页默认首先展示状态机。
- 真正拖动节点改变坐标；方向键移动也有效。从端口拖线和“点端口再点目标”都能创建可执行转换，右侧正确显示来源与目标。端口命中区域扩大至 34 px（图坐标），避免小圆点难以操作。
- 编辑来源、条件、目标；撤销回到旧目标，重做恢复新目标。刷新后自定义规则和单独保存的节点位置均恢复。切换球队隔离编辑历史。
- 示例包含状态专属连线；运行状态、候选转换与编辑选择使用不同颜色。暂停、单步、继续可用；死球和规则编辑不会把候选错误标为已执行。
- 375 px 外框的实际内容宽度为 360 px，页面 scrollWidth 同为 360，无页面级横向溢出。图可在自身容器内滚动；点击端口、创建边、编辑 guard 均可操作，创建边后定位到下方编辑面板。该项使用窄 iframe，不是原生手机硬件。
- 比赛 / 职责 / 跟踪视图可切换。默认战术镜头，职责色环、球队号码、蓝色参考与红色实际速度箭头显示。球的高度阴影、选中标记、点击检测使用一致的插值位置；无需外部 CDN。
- 同步网络视图点击 #3 Cameron，选择器更新到同一球员。比赛阶段时间轴显示实际转换和有效间隔。
- 阵地防守筛选仅 0 个有效间隔时，拟合按钮禁用并提示还需 40 个；切回充分数据窗口后拟合可执行。

## 明确边界

- 这不是完整 DES 监督控制器综合、形式化非阻塞验证或全局任务可行性证明。
- 外场球员任务状态机与门将独立策略不同；图中的结构检查不是球场表现保证。
- 图的浏览器布局不随战术 JSON 导出；可执行规则会导出。
- 实际验收为云端 Canvas 兼容路径；不能据此承诺原生手机触控或硬件 WebGL 的持续帧率。界面曾观察到约 5–7 ms 单帧绘制耗时，但这不等同于完整主线程或持续帧率基准。
- 新优先级不保证每种控制器、球队或参数下都避免停滞。任务冲突、信息陈旧、低秩辨识等情况仍应通过诊断、固定起点比较和事件证据判断。
- 旧版 benchmark 和报告仍保留并使用旧文件名，供兼容性复现；本版本新浏览器证据使用 v1.5 前缀。
