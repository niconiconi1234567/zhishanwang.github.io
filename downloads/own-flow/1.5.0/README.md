# OWN / FLOW v1.5.0 · Visual Mission Automata

2026-11-11。完整静态源代码与 Cloudflare Pages 部署包。ZIP 根目录就是 `index.html`；可直接上传压缩包，无需构建、安装依赖或配置密钥。本包尚未部署到用户的线上地址。

## 从这里体验升级

1. **赛场 → 设计任务状态机**。也可进入战术工作室，第一个标签就是任务状态机。点击“载入状态链示例”，看到保持阵型 → 上压 → 恢复的状态链。
2. **拖动卡片，或从圆形端口拖线到另一状态**。也支持先点端口、再点目标；键盘方向键移动节点。点击一条边，在右侧修改来源、条件、目标、启用状态和优先级。支持撤销、重做、整理布局和缩放。手机窄屏会将编辑面板放到图下方，创建边后自动定位到面板。
3. **暂停 / 单步 / 继续** 检查真实跳转。薄荷色是所选球员实际状态，蓝框是编辑选择，金色是待确认转换。卡片人数是当前球队实际分布。候选条件不再被标作已经触发的规则。
4. **赛场 → 比赛 / 职责 / 跟踪**。默认固定战术镜头。职责视图有球队号码、任务色环和所选球员参考；跟踪视图比较蓝色目标箭头与红色实际速度箭头（按 1 秒位移绘制），不是两条同量纲误差曲线。草皮和看台换用新的原创纹理。
5. **战术 → 球权任务优先级**。争球、上压、持球阶段的有效队形权重为 `shapeWeight × (1 − contactPriority)`，其他职责保留原权重。新预设默认 0.85，可调至 0 重现原权衡。它解决了一个已复现的“阵型约束抵消争球指令、停在触球距离之外”的情况，不保证每场比赛更优。
6. **多智能体工作台 → 交互辨识**。阶段时间轴、可点击阶段标签、有效间隔进度和下一步提示一起显示。达到 40 个有效间隔后才能开始拟合；通过样本门槛仍不代表网络边可辨识。低秩或验证无改善时保留明确诊断，不强行画边。
7. **任务与事件**。选择事件看历史位置快照、来源状态、目标状态、规则和证据；可导出 HTML 报告及 JSON。控制训练场中的 PID、ADRC、受约束 MPC、接线、传递函数、零极点和 A/B 流程继续保留。

首次进入新的站点来源时，双方启用均衡任务策略。已有浏览器草稿保留原设置；如果界面显示“任务控制未启用”，选择一个预设即可。旧任务策略缺少 `contactPriority` 时按 0 导入，保持原来的权重。选择新版预设才启用新的默认权衡。

## 状态机的准确语义

- 外场球员使用 8 个固定任务状态；门将保留独立策略。最多 16 条转换。规则具有稳定 ID、来源状态（`*` 表示任意状态）、guard、目标和优先级。
- 来源与 guard 同时满足才参与优先级选择；时序确认及执行前提随后检查。没有符合条件的出边时保持当前有效状态。自环不重置驻留时间。
- 失去球权、证据过期、缺少可见封线路线及公开死球仍有系统退出。保护交接仍需要新鲜的到位 ACK，不能靠删边取消必要前提。
- 图中“有路径”只是结构检查，不是监督控制器综合、非阻塞证明、任务可行性或整场稳定性证明。
- 拖动只改布局，不改策略版本、驻留计时或固定任务期限。语义编辑重置候选确认计时，不重置已有职责期限。
- 布局按球队保存在当前浏览器；战术导出包含可执行规则，**不包含节点布局**。恢复的当前状态和策略编辑选择分别显示。
- 球场全局职责叠加不会出现在局部球员视角；局部控制器仍只使用观测与收到的消息。

## 保存与兼容

应用和新存档版本为 1.5.0；可读取 1.4.0、1.3.0、1.2.0、1.0.0 的受支持存档。旧存档不能补造过去未记录的任务事件。数据按浏览器与网站来源隔离；继续使用同一个 Pages 项目地址可保留本地设置，换域名前先导出数据。

实时列表保留最近 60 条事件；报告保留最近 2,400 条并标明省略量；阶段汇总覆盖整个已监测过程。长实验请定期导出。

完整记录见 `maintenance/TEST_REPORT.md`。旧版样本保留原名；新浏览器样本以 `v1.5-` 开头。私人 Football Research 原文未放入部署包。

| 模块 | 职责 |
|---|---|
| `mission-core.js` | 局部状态机、时序、交接、状态相关队形权重 |
| `mission-graph.js`, `mission-graph.css` | 拖动、连线、检查器、撤销与运行高亮 |
| `mission-visual.js` | 两种渲染器共用的职责与跟踪叠加 |
| `phase-workflow.js` | 与拟合器一致的有效间隔统计和阶段时间轴 |
| `task-monitor.js` | 固定期限、阶段汇总、事件证据 |
| `maintenance/MISSION_METHODS.md` | 研究联系及模型判定范围 |

本版本验证桌面浏览器、375 px 内容容器与 Canvas 兼容渲染。原生手机触控和真实硬件 WebGL 帧率仍需设备验收；没有声称达到商业足球游戏画质。
