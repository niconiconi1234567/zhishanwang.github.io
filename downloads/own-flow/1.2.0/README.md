# OWN / FLOW v1.2.0 · Control Ground

2026-11-02。将完整 ZIP 上传到现有 Cloudflare Pages 项目的新部署。`index.html` 位于压缩包根目录。运行时使用本地 ES modules、Web Workers、Three.js、场景纹理与数学字体。部署无需构建命令、服务端或密钥。开发时通过 HTTP/HTTPS 打开。

## 三分钟体验

1. 打开 **控制训练场 → 球场演示**，选择“指定值共识”。参考为 6 m。点击“运行”看球员移动，或点“算到终点”计算完整 30 秒。蓝色虚线与目标环标示参考，红橙色轨迹与箭头标示实际输出。响应曲线可查看具体时刻的数值。
2. 改选“断网分群”。在“拖拽接线”看两个没有跨组边的环。在球场上查看各分量的均值和组内跨度，区分组内一致和全队一致。点击两个球员可添加或移除通信边。
3. 选择“归零共识”，切到“拖拽接线”。拖动模块改变位置。从绿色输出端拖到蓝色输入端改变信号关系，也可依次点击两个端口或用下拉框连接。内置直接反馈、参考和测量滤波、正反馈、断开外层反馈、单位增益直通五种接法。连接缺失时页面标出待接端口。
4. 在“传递函数与极点”查看当前接线的名义离散传递函数、单位圆、约分后极点、全部内部极点以及 11 个网络模态。选择正反馈后返回球场，观察实际位移如何偏离目标。
5. 在“配对评测”用三个相同种子比较 P、PID、ADRC 和 MPC，或者比较同质对象与所选阵容的异构对象。报告支持查看首组曲线、逐种子指标、配对差值区间和导出 JSON。

## 训练对象与比赛中的作用

每个训练球员的横向位移为一阶连续对象的状态。模型为 ẋᵢ = axᵢ + bᵢ(uᵢ + d)。程序以 0.1 s 精确零阶保持离散化，11 名球员先读取同一采样时刻的状态，再同步推进。共同的 0.7 m/s 前进运动将横向控制响应展开为场上轨迹。位移超过 80 m 时保留真实数值并提前停止。画面在场界处保留出口方向，分析曲线保留完整输出。

设 D 为参考锚点对角阵，L 为配置图拉普拉斯，g 为通信边权，m 为当前测量。负反馈的误差为 e = D·1·rF − (gL + D)m。正反馈切换求和符号，断开反馈移除外层网络项。F、H 通过接线启用对应一阶滤波器。未锚定时蓝线显示用于评价的初始全队均值。无扰动、无输入限幅的同质积分器采用对称图比例一致性协议时保持算术均值。

| 控制器 | 实际执行 |
|---|---|
| P | 比例误差与输入限幅 |
| PID | 独立积分记忆、滤波微分、条件积分抗饱和 |
| 一阶 LADRC | 两状态扩张观测器、总扰动估计、基于局部观测的扰动补偿 |
| MPC | 带输入箱约束的有限时域二次优化，每个采样点执行最优序列的第一项 |

传递函数取零初态。极点分析针对当前接线的同质、同步、未触发限幅的线性实现。MPC 在约束未激活区域具有对应局部线性响应。网络模态使用 gL + D 的特征值，参考对每个模态的实际激励由锚点投影决定。稳定性判定包含被传递函数相消的内部模态。控制器公式和方法出处见 `maintenance/CONTROL_METHODS.md`。

在训练场选择“应用角色跟踪器”后，所选球队在真实比赛中用这套控制器和本地滤波计算两轴角色跟踪修正，保留原有邻居关系项、任务分项、补偿器、持球逻辑及运动约束。训练场的自定义通信图作用于受控训练实验，比赛使用球队自己的战术图与感知。可直接“观看比赛”或“比赛消融对照”，比较同一球队启用和移除跟踪器的真实表现。比赛 A/B 可选择干预蓝队或红队。场上进失球、射门、传球尝试均按实验窗口计数。

## 草皮、教练板与异构阵容

- Canvas 透视兼容渲染和 WebGL 使用同组原创草皮、草叶凹凸、分区看台和围板材质。表面加入割草方向与门前磨损。近景体现体型、身高、支撑脚接地、制动和触球动作。
- 战术工作室的“经典战术”包含短传三角、深守反击、高压夺回、三中卫双翼卫、自由人链式防守。每套含完整 11 人、阵型、子系统、关系图、通信图与传球策略。传球选择只读取持球人可见的证据。
- 人物、球衣、队名和场景采用原创设计。历史队伍用于说明战术来源。个别身体/速度参照有官方资料，其他能力是明确标注的实验参数。各资料卡和 `maintenance/FOOTBALL_SOURCES.md` 提供出处及模型映射。
- 同质对照将速度、加速度、技术、初始体能和视野各自替换为本队均值。训练场的“异构强度”控制 bᵢ 与加速度之比以及 Uᵢ 与最高速度之比。在比赛中相应能力直接作用于运动、观察和出球。运行中载入配置后，下一场新比赛采用该阵容的初始体能。
- 控制实验室的“多智能体分析”区分配置图和观测器实际使用的有向状态消息。可检查 2.5 秒新鲜度、每名球员的接收覆盖、单向/双向链路、强连通分量和本帧多跳可达数。
