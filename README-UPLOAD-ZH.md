# V7 网站上传说明

下载 `zhishan-website-v7-full.zip`，解压后把里面的全部文件和目录上传到现有 GitHub Pages 发布目录。若现有主页在仓库根目录，就上传到根目录。若原来使用 `docs/` 发布，就上传到该目录。上传后，`index.html` 与 `assets/`、`talks/`、`publications/`、`downloads/`、`media/`、`archive/` 应在同一层。保留仓库已有的域名与部署设置。

完整包已带齐网站图片、会议原稿、演示视频、三个救援视频、六版足球平台源码及演讲文件。无需安装软件或另行上传图片。单独提供的配图 ZIP 供复用原图，源码 ZIP 供后续维护。

## 上传后查看

1. 在首页选 **ICARCV 2026 · Oral presentation**，进入论文后点 **View oral presentation**。
2. 阅读器可逐页翻阅，也可用下拉框选择页码。选 **Play the demo** 可播放第 25 页的原始视频。页面底部有 PDF 和 PowerPoint。
3. 在 **Papers** 选择 **Accepted** 并搜索 **ICSC**，能看到波尔图的两篇论文。每篇都提供原稿、公式说明和数据图的原始页码。

PPTX、演讲 PDF、逐页画面和视频位于 `talks/icarcv-2026/`。论文原稿位于 `publications/`。网站使用相对路径，可以沿用现有 GitHub Pages 地址。
